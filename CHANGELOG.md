# Changelog

All notable changes follow Keep a Changelog. Versioning follows SemVer.

## [0.1.0-alpha.1] - 2026-08-03

### Added

- Single Hermes provider with asymmetric Hindsight/Mnemosyne routing.
- Hindsight REST adapter and Mnemosyne public-Python adapter.
- Durable SQLite outbox, mappings, retries, audit trail, and deletion tracking.
- Secret redaction/rejection and bounded context.
- Primary-context-only automatic writes.
- CLI, installation scripts, production/staging examples.
- Architecture, routing, threat model, privacy, configuration, recovery,
  compatibility, development, operations, and data-model documentation.
- Unit and integration-style tests plus GitHub Actions.
