# Governance

The project uses a maintainer-led model.

- Initial maintainer: `@l1lchucky`
- Security-sensitive changes require maintainer review.
- Database schema, routing-policy, redaction, and backend adapter changes require
  explicit compatibility and threat-model review.
- Releases are created from protected branches after required checks pass.
- Additional maintainers may be appointed based on sustained, trusted
  contributions.
