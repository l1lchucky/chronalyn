# Governance

Hermes Memory Router is maintainer-led.

- Initial maintainer: `@l1lchucky`
- Security-sensitive changes require maintainer review.
- Routing, database, redaction, and adapter changes need a compatibility and
  threat-model review.
- Releases are cut from a protected branch after required checks pass.
- New maintainers may be invited after sustained, careful contributions.

Project decisions should be recorded in issues or architecture decision records
so users can understand why a change was made.
